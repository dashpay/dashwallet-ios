# Username voting review captures

Captured on 2026-11-09 on an iPhone 17 simulator (iOS 26.5, light appearance) with a new wallet
that holds no masternode voting keys, against the open contests on mainnet at that time. The
contests come from the network: the names, counts and voting ends are whatever was open then.

- `before-*`: develop at `7defb2472`, before the redesign.
- `stage1-list`: the list restyle (stage 1).
- `stage2-*`: the Filters sheet and a filtered list (stage 2).
- `stage3-*`: the list on the shared store and Request details opened from a row (stage 3).

Two captures are cropped at the bottom to leave out offensive usernames that were open on the
network. No several-request contest was open, so the expanded row is not captured here.
